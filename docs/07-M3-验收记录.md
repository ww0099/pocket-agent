### 1.1 交互能力

- 流式文本输出、代码高亮、标题/列表/链接/表格渲染；
- 工具调用卡片：运行中 / 成功 / 失败、耗时、参数摘要、首行输出；
- 审批弹窗：`a` 允许本次、`A` 本项目始终允许、`d` 拒绝；
- `A` 会写入 `<project>\.agent\permissions.json` 并立即生效；
- 斜杠命令：`/help` `/clear` `/model` `/provider` `/permissions` `/cost` `/status` `/compact` `/quit`；
- 状态栏：Provider / 模型 / 权限模式 / token 用量 / 会话 ID；
- Ctrl+C：生成中取消；空闲时退出；Ctrl+D 退出；
- 终端不支持 TUI 或指定 `--plain` 时自动回退行式交互；
- 恢复会话时，TUI 会把历史 user/assistant 文本重新渲染出来。

### 2.1 三模式选择逻辑

```text
有提示词（-p 或位置参数）        → headless（单次输出）
无提示词 + --plain               → plain 行式交互
无提示词 + stdin/stdout 不是 TTY → 自动 plain
无提示词 + 真 TTY                → Ink TUI
TUI 启动异常                     → 自动回退 plain
```
