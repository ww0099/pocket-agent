### 1.1 模型列表

- 工具此前并非“只能读 chat 模型”；`--list-providers` 只显示配置中的模型名。
- 新增 `--list-models` / `/models`，向服务商 `/models` 端点拉取真实列表。
- DeepSeek 实测返回：`deepseek-flash`、`deepseek-v4-pro`。
- `deepseek-flash` 已实测可对话。
- 智谱示例：`zhipu`（`glm-4.1-flash`，需 `ZHIPU_API_KEY`）；若官方模型名不同，以 `/models` 结果为准。

### 1.2 扩展能力

- **Skills**：扫描全局 `skills/` 与项目 `.agent/skills/`，项目覆盖同名；系统提示只放摘要，正文通过 `Skill` 工具按需加载。
- **Subagents**：`agents/*.md` 定义工具白名单、模型、最大轮数；上下文隔离，只回传最终结论；递归深度限制 1。
- **自定义命令**：`commands/*.md` 与项目 `.agent/commands/`，支持 `${1}`、`${@}`、`$ARGUMENTS`；TUI/plain/headless 均可展开。
- **MCP**：stdio 与 Streamable HTTP；工具命名 `mcp__server__tool`；只读注解参与并发与权限；连接失败不阻塞启动。
- **Hooks**：PreToolUse / PostToolUse；退出码 2 阻止执行；超时与取消处理。

## 4. 已知限制（诚实口径）

| 限制 | 说明 | 计划 |
|---|---|---|
| MCP HTTP 未做真实 E2E | 代码支持 Streamable HTTP，本次只实测 stdio | M6/后续按实际 Server 验证 |
| MCP 参数校验依赖 Server | 客户端只用 Zod 校验为对象，JSON Schema 由 Server 最终校验 | 可加 ajv |
| Subagent 用量未计入父会话费用 | 子 Agent 的 usage 未累加到 `/cost` | 后续修复 |
| frontmatter 为简化解析器 | 支持 key/value、行内数组、块数组、布尔/整数；不支持多行 `|`/`>` | 需要时再扩展 |

| TUI 仍未人工按键验收 | 与前几个里程碑相同 | 请在 Windows Terminal 实测 |
