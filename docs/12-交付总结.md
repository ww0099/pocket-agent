## 1. 一句话

PocketAgent 是一个放在 U 盘里的 AI 编程 Agent：插上任意 Windows x64 电脑即可启动，运行时、配置、会话、技能、记忆全部随盘携带，不依赖系统 Node，不需要安装。

---

## 2. 当前可用能力

| 层 | 能力 |
|---|---|
| 交互 | Ink TUI、plain 行式、headless `-p` |
| 模型 | Anthropic 原生 + OpenAI 兼容（DeepSeek / 智谱 / OpenRouter / Ollama 等） |
| 模型发现 | `--list-models` / `/models`（DeepSeek 实测：`deepseek-flash`、`deepseek-v4-pro`） |
| 工具 | Read / Write / Edit / Glob / Grep / Bash / TodoWrite / MemoryWrite / Skill / Task |
| 权限 | 四种模式、规则 DSL、路径守卫、敏感路径、危险命令拦截、审批菜单、项目级持久授权 |
| 会话 | JSONL 追加写、压缩记录、`--continue` / `--resume`、权限审计 |
| 上下文 | token 估算、自动/手动压缩、压缩后复灌、`/cost` |
| 记忆 | `AGENTS.md` / `CLAUDE.md`、全局与项目 `MEMORY.md` |
| 扩展 | MCP（stdio + HTTP）、Skills、Subagents、自定义命令、Hooks |
| 运维 | `--check`、`/doctor`（自检）、`upgrade.cmd`、C 盘审计脚本、启动基准脚本 |

## 3. 快速使用

```powershell
# 在项目目录启动 TUI
E:\agent\agent.cmd

# 单次对话
E:\agent\agent.cmd -p "解释这个仓库的结构"

# 行式交互
E:\agent\agent.cmd --plain

# 自检
E:\agent\agent.cmd --check

# 模型列表 / 切换模型
E:\agent\agent.cmd --list-models
E:\agent\agent.cmd --model deepseek-flash -p "只回复 OK"
```

TUI 内常用：

```text
/help  /model  /models  /provider  /permissions  /cost  /compact  /clear  /quit
```

审批菜单：

```text
1 = 允许本次
2 = 本项目始终允许（写入项目 .agent/permissions.json）
3 = 拒绝
先选择，再按 Enter；未选择时 Enter 不生效。
也可用 ↑/↓、Tab 或 a / Shift+A / d。
```

## 6. 安全与限制

### 6.1 安全

- API Key 明文保存在 `config\secrets.json`；U 盘遗失即密钥暴露。若曾通过聊天传递，建议轮换后更新。
- 不要把整个 `E:\agent` 上传网盘或 Git 仓库。
- Bash 等价于以当前用户身份执行任意代码；权限系统防误操作，不是沙箱。
- 第三方 MCP Server 与 Hooks 是用户配置的可执行代码，使用前应审查来源。
- C 盘审计脚本只监视 C Temp 与 npm 缓存；完整内核级审计可在干净 VM 用管理员 Procmon 复核。

### 6.2 已知限制

| 限制 | 说明 |
|---|---|
| ripgrep 未内置 | GitHub 直连被重置、可信镜像无文件；Grep 走 JS 回退（上限 5000 文件 / 单文件 1MB） |
| 干净虚拟机验收未做 | 当前机器已装 Node/Git；建议在无 Node/Git 的 Windows 10/11 虚拟机跑一遍 |
| MCP HTTP 未做真实 E2E | 代码支持 Streamable HTTP，本次只实测 stdio |
| Subagent 用量未计入父会话费用 | 子 Agent 的 token 不计入 `/cost` |
| frontmatter 简化解析 | 支持常用 key/value、行内/块数组；不支持完整 YAML 多行语法 |
| `/cost` 金额需单价 | token 统计正常；金额需在 `providers.json` 的 `pricing` 填单价 |

```powershell
E:\agent\upgrade.cmd -Source D:\新版本目录

# 自检
E:\agent\agent.cmd --check

# 清理测试工作区（示例）
Remove-Item -LiteralPath 'E:\agent\workspace\tui-test3' -Recurse -Force

# 查看会话
Get-ChildItem -LiteralPath 'E:\agent\data\sessions' -Recurse -Filter *.jsonl
```

升级前会自动备份到 `backup\<时间戳>`；如升级异常，可从备份恢复 `app/runtime/tools`。
