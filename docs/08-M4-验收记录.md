### 1.1 上下文治理

- 系统提示自动注入：
  - 从 cwd 向上查找最近的 `AGENTS.md`，没有则用 `CLAUDE.md`；
  - 全局 `memory/MEMORY.md` 与项目 `.agent/memory/MEMORY.md`；
  - 索引硬截断：200 行 / 25KB，超限提示整理。
- 压缩触发：`(maxContextTokens - maxOutputTokens) × 0.75`。
- 压缩策略：摘要较早对话，保留最近 8 条，并保证不从 tool_result 中间切断。
- 压缩后复灌：工作目录、权限模式、Provider/模型、已修改文件、待办。
- 摘要失败自动降级为截断，不阻塞任务。
- 手动 `/compact` 随时可用。
- 压缩写入 JSONL 的 `compaction` 记录；恢复时以“摘要 + 保留消息”重建，原始记录保留用于审计。

### 1.2 记忆

- `MemoryWrite` 支持 `project` / `global` 两种作用域；
- 必须提供 `reason`，便于追溯；
- 文件带 frontmatter（name / description / type / created）；
- 自动维护 `MEMORY.md` 索引，重复写入只追加更新段落。

### 1.3 费用

- Provider 配置新增可选 `pricing`（每百万 token 价格、货币、缓存价格）；
- `/cost` 输出输入/输出/缓存 token 与估算费用；
- 未配置价格时明确提示，不猜测金额。

## 3. 已知限制（诚实口径）

| 限制 | 说明 | 计划 |
|---|---|---|
| TUI 仍未人工按键验收 | 与 M3 相同，当前环境无交互式终端 | 请在 Windows Terminal 实测 |
| 摘要质量依赖模型 | 弱模型可能漏掉关键决策；已提供降级截断 | 可在压缩指令中强化，M5 后优化 |
| 超大单条提示无法压缩 | 若当前用户消息本身就超过窗口，cut=0，不会压缩，可能被服务端拒绝 | 提示用户拆分任务 |
| 价格默认 0 | 模板只给结构，不猜服务商价格 | 用户在 `providers.json` 填 `pricing` |
| 记忆索引不自动清理 | 超过 200 行才截断，需人工整理 | M5 可加记忆整理命令 |
| 压缩记录会复制保留消息 | 审计友好，但会话文件会变大 | 可接受，后续可优化 |
| token 估算为启发式 | CJK 1 字/token，其余 3.5 字符/token | 仅用于触发压缩，不用于计费 |
